# Journal de construction

Ce dossier tient le journal des sessions de travail sur ce portfolio. Un
fichier par session, horodaté, écrit à la fin de la session et jamais
retouché après.

Il est public **volontairement**. L'accueil du site annonce que l'IA est
intégrée au quotidien dans le processus de travail ; ces rapports sont la
pièce qui le montre, plutôt que de le dire.

## Comment le lire

- **Les décisions font foi ailleurs.** `DESIGN.md` porte les décisions de
  design, `CLAUDE.md` et `.claude/rules/` les règles du dépôt. Ici, c'est le
  chemin qui y mène.
- **Les fausses pistes sont gardées exprès.** Chaque bug non trivial est
  consigné en symptôme / fausse piste / cause / correction. Ce qui n'a pas
  marché renseigne autant que la solution retenue, et une cause trouvée du
  premier coup est rare assez pour qu'on le dise quand ça arrive.
- **Un essai abandonné reste écrit.** Les mots clés de l'accueil ont porté
  l'encre une demi-journée avant d'être rendus au noir : le rapport du
  13/11/2026 dit pourquoi, avec la mesure qui a tranché.

## Ce qui n'y entre pas

Un emploi du temps, une estimation, un commentaire sur un tiers. Rien non
plus qui ne soit déjà public ailleurs dans ce dépôt ou sur le site.
