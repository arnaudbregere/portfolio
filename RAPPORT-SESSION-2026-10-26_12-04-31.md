## 5. Problèmes rencontrés et corrections

| Symptôme | Cause | Correction |
|---|---|---|
| `[sass] Error: There's already a module with namespace "index"` au build | Trois couches ITCSS nommées `_index.scss` (`objects`, `components`, `utilities`) : même espace de noms pour `@use` | Renommage en `_objects.scss`, `_components.scss`, `_utilities.scss` |
| `npm install` refusé : `Conflicting peer dependency: vitest@3.2.7` | `@nuxt/test-utils` 3.x exige Vitest 3 | Première tentative : rétrograder Vitest en 3.x. Mauvaise piste — voir ligne suivante |
| Vitest s'arrête sur `Unknown Error: [object Object]`, aucun test collecté | Vitest 3 embarque Vite 7 alors que Nuxt 4.6 fournit Vite 8 : incompatibilité silencieuse, message inexploitable | Montée à `@nuxt/test-utils` 4.3.4 avec Vitest 5. Les tests passent |
| `npm run typecheck` : `ERR_PACKAGE_PATH_NOT_EXPORTED` sur `vue-router/volar/sfc-route-blocks` | `vue-router` déclaré en `^4.6.3` alors que Nuxt 4.6 génère un `tsconfig` référençant `vue-router/volar/*`, sous-chemin qui n'existe qu'à partir de la 5.x | Montée de `vue-router` en `^5.4.0`, version dont dépend Nuxt lui-même |
| Nuxt : `Current version of Node.js (20.19.5) is unsupported` | Nuxt 4.6 exige Node `^22.21.0 \|\| ^24.11.0 \|\| >=26.0.0` | Installation de Node 22.23.4 par nvm, `.nvmrc` à `22`, `node-version-file` dans la CI. Le `default` nvm de la machine n'a pas été modifié |
| `npm run lint` : 48 erreurs dans des fichiers jamais écrits par nous | ESLint analysait les scripts vendorisés du skill `impeccable` | `ignores: ['.claude/**', '.specify/**']` dans `eslint.config.mjs` |

Deux actions ont été refusées par le classificateur d'auto-mode, contournées
sans perte :

- `curl ... | node -` pour `caveman-init` (exécution de code distant) : script
  téléchargé dans le répertoire de travail temporaire, lu, puis `AGENTS.md`
  écrit à la main à partir de la règle exacte extraite du fichier.
- `gh repo create --push` en une commande : découpé en création du dépôt vide,
  `git remote add`, puis `git push`.
